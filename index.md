# Home page

The `index.md` page is the default page for any folder, and this file is the landing page for the whole site.

Explore the navigation bar to the left; it is configured in `sidebars.yaml` and provides links to other pages.
The structure of the folders are used as the default URLs where the content is displayed.

## Page structure

Subheadings on a page are shown in the right-hand bar if your screen is wide enough.
This feature is more interesting and useful when the page is longer than this one is!
Users can more easily orient themselves within a longer document with this feature.

## More information

The links on the left have more information about some key features for writers.

## Try the examples

Use the pages in the navigation as examples when building your own documentation. They show patterns for code samples, tables, tabs, diagrams, and Markdoc content. Adapt the examples to fit your project, and add new pages to `sidebars.yaml` so readers can find them.
